## 🏷️ 二、 章节标题与节次命名绝对规范（严格与课本 PDF 保持 100% 一致）

> [!IMPORTANT]
> **【标题绝对对齐原则】**：
> 1. **章标题与节标题必须与课本 PDF 目录和正文节标题 100% 保持一致，一字不差**；
> 2. **严禁自行添加任何修饰性后缀或自造短语**（例如：节标题如果课本原文是「第2节 供给」，严禁自作主张写成「第二节 供给理论与供给函数随堂测算」或「第二节 供给理论」等）；
> 3. **过渡页（Bridge）、总览页（Overview）、内容页导航小标（Nav）与封面页（Cover）必须全链路严格采用课本原节名**；
> 4. 课本附录如果独立成节或展开，标题必须严格遵循课本附录原名称（如「附录 在需求曲线的背后：消费者选择理论」）。

## 🔄 三、 「习题跟着内容走」讲练融合编排规范 (In-situ Exercise Flow)

> [!IMPORTANT]
> **【讲练融合一体化原则】**：
> 1. **杜绝教材内容与习题割裂**：严禁将全章例题、案例与课后习题集中堆砌在课件最后几页；
> 2. **习题紧随理论**：课本例题（如【例 1-1】、【例 2-1】）、课本案例（如【案例 2-1】、【案例 4-1】）以及针对该节知识点的课后重点复习思考题与作业题（如【作业题 2】、【作业题 4】），**必须紧随对应节次的核心理论与几何模型展开**；
> 3. **闭环教学逻辑**：
>    * 第一步：讲解核心概念与数理定理；
>    * 第二步：通过 300 DPI 矢量学术图表进行几何模型图解；
>    * 第三步：立即跟进教材例题或课后作业题进行分步代数求解；
>    * 第四步：引入教材经典案例进行管理实践印证。

## 🎨 四、 纯净视觉体系（零双引号 ＋ 原生加粗富文本解析）

> [!TIP]
> **【纯净视觉规范】**：
> 1. **彻底清除多余双引号**：页面正文中严禁充斥大量中英文双引号（`"`、`“`、`”`、`\"`），彻底剔除冗余引号，保持版面通透干练；重点词汇改用颜色或加粗进行视觉分层；
> 2. **原生富文本加粗解析（消除 Markdown 符号残留）**：
>    * 使用 `slide_generator_engine.py` 中的 `add_rich_paragraph` 解析 Markdown 的 `**重点文字**`；
>    * 自动将其分割为独立的 PPT 文本 Run 并设置 `run.font.bold = True` 与指定颜色（如 `#1B3A5C` 或 `#C84B1B`）；
>    * 保证输出的 PPT 中 **0 个 `**` 残留符号**。

## 📐 五、 数学符号与公式规范（100% 杜绝 LaTeX 源码与乱码）

> [!CAUTION]
> **【数学与物理符号出版级规范】**：
> 1. **严禁在 PPT 文本中输出任何 LaTeX 模式定界符 `$` 或 `$$`**（例如必须输出 `P`、`Qd`、`P*`，严禁输出 `$P$`、`$Q_d$`、`$P^*$`）；
> 2. **严禁输出未经转换的原始 LaTeX 语法代码**（如 `\times`, `\sum`, `\Delta`, `\alpha`, `\beta`, `\frac`, `_{...}`, `{}` 等）；
> 3. **全自动转化为规范的自然学术字符**：

| 原始 LaTeX 源码 | 强制规范转换符号 | 示例及标准输出效果 |
| :--- | :--- | :--- |
| `$P$`, `$I$`, `$Q_d$`, `$P_r$` | **`P`, `I`, `Qd`, `Pr` (自然变量)** | `Qd = f(P, I, Pr, T, E, N)`（严禁带 `$` 或 `_`） |
| `\times` | **`×` (标准乘号)** | `50 × 0.75 = 37.5`（严禁输出 `50 \times 0.75`） |
| `\cdot` | **`·` (点乘符号)** | `MR = P · (1 - 1/Ep)` |
| `\sum` | **`∑` (求和符号)** | `V = ∑ [CFt / (1+r)ᵗ]` |
| `\Delta` | **`Δ` (变化量/差额)** | `ΔNPV = +18.2 万元`, `ΔCS = -20 元` |
| `\alpha`, `\beta`, `\gamma`, `\mu`, `\sigma` | **`α`, `β`, `γ`, `μ`, `σ`** | `期望值 μ`, `标准差 σ`, `肯定当量 α` |
| `\pi`, `\Pi`, `\lambda`, `\rho`, `\theta` | **`π`, `Π`, `λ`, `ρ`, `θ`** | `利润 π`, `影子价格 λ`, `相关系数 ρ` |
| `^2`, `^3`, `^n`, `^t`, `^*` | **`²`, `³`, `ⁿ`, `ᵗ`, `*` (标准上标/幂次)** | `R² = 0.92`, `Q² - 80Q + 1000 = 0`, `(1+r)ⁿ`, `P*` |
| `\frac{A}{B}` | **`(A / B)` (规范除法/分式)** | `CV = (σ / μ)`, `EAC = (总成本 / PVIFA)` |
| `\sqrt{A}` | **`√(A)` (标准开根号)** | `σ = √(784) = 28 万元` |
| `\le`, `\ge`, `\ne`, `\approx`, `\infty` | **`≤`, `≥`, `≠`, `≈`, `∞`** | `|Ep| ≥ 1`, `WACC ≈ 11.96%`, `EMV = ∞` |
| `_{10%,3}`, `_{max}` | **`(10%, 3期)`, `max` (规范下标/注记)** | `PVIFA(10%, 3期)`, `EMV max` |

## 📊 六、 课本图表保留与真实嵌入规范（1/2 黄金保留法则）

> [!IMPORTANT]
> **【图表 1/2 保留与生成原则】**：
> 每章若有图表，课件中保留的图表数量**严格按照课本图表总数量的 1/2 比例进行精选保留**，优先选取最具理论核心价值与决策解释力的前 50% 核心图表，并通过 Python `matplotlib` 动态生成并在 PPT 中真实嵌入：
> 1. **优先保留图表类型**：核心模型几何图（供求、弹性、成本、市场结构、差别定价）、关键决策流程图与博弈收益矩阵；

## 💻 九、 脚本资源与自动化流水线调用 (Script Pipeline)

本技能在 `scripts/` 目录下内置了全套开箱即用的自动化 Python 脚本：
* `scripts/slide_generator_engine.py`：PPTX 核心生成引擎（含 `sanitize_math_text`、`add_rich_paragraph` 与 `add_image_card`）；
* `scripts/safe_save_helper.py`：多层级安全保存助手（解决 Windows PowerPoint 文件锁定引发的 PermissionError）；
* `scripts/audit_deck.py`：自动化全维度质检审计脚本（检查页数、图表数、0双引号、0星号、0LaTeX乱码）。

调用示例：
```python
from slide_generator_engine import create_deck
from safe_save_helper import safe_save

# 构建 16:9 画布、富文本加粗解析、零双引号清洗、嵌入 1/2 核心图表并安全保存
deck = create_deck(book_title, sub_title, chapter_title, desc, slides_data)
safe_save(deck, target_path)
```
