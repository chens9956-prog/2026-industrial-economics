# 金牌学术课件设计基准规范 (Benchmark Specification)
> 锚定基准样本：`L:\我的云端硬盘\2026产业经济学\第十四章_统筹发展和安全.pptx`

## 🎯 一、 核心视觉定位与画幅

* **画幅比例**：`16:9` 宽屏高清（宽 `13.333 英寸` × 高 `7.500 英寸` / `33.867 cm × 19.050 cm`）。
* **版面留白率**：严格保持 35%~40% 呼吸空间，全页不留大面积空白，但单卡片严禁文字溢出挤压。

## 📐 四、 经典版式几何坐标与构件库

### 1. 经典双栏卡片布局 (2-Column Cards)
* **左卡片**：Left `0.50"`, Top `1.45" ~ 1.55"`, Width `5.90" ~ 6.00"`, Height `4.60" ~ 5.00"`
* **右卡片**：Left `6.85"`, Top `1.45" ~ 1.55"`, Width `5.90" ~ 6.00"`, Height `4.60" ~ 5.00"`

### 2. 经典三栏指标卡布局 (3-Column Cards)
* **每栏尺寸**：Width `3.90" ~ 3.95"`, Height `4.60" ~ 5.00"`
* **横向坐标**：Col 1: `0.50"`, Col 2: `4.68"`, Col 3: `8.86"`

### 3. 经典四栏矩阵布局 (4-Column Matrix)
* **每栏尺寸**：Width `2.85" ~ 2.90"`, Height `4.60" ~ 5.00"`
* **横向坐标**：Col 1: `0.50"`, Col 2: `3.60"`, Col 3: `6.70"`, Col 4: `9.80"`

### 4. 重点领域五栏协同矩阵 (5-Column Matrix)
* **每栏尺寸**：Width `2.35"`, Height `5.10"`
* **横向坐标**：Col 1: `0.50"`, Col 2: `2.95"`, Col 3: `5.40"`, Col 4: `7.85"`, Col 5: `10.30"`

### 5. 底部总结金句条 (Bottom Takeaway Bar)
* **几何尺寸**：Left `0.50"`, Top `6.45" ~ 6.75"`, Width `12.33"`, Height `0.45" ~ 0.55"`
* **视觉样式**：暖杏底（`#FDF6E3`）或极淡灰底，带 1pt 金色/绿色边框，文字 `13pt` bold 居中。
