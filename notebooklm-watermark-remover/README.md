# ✨ NotebookLM 水印粉碎器 Pro (Watermark Remover Pro)

专为一键精准、无损去除 **NotebookLM** 导出的 **PDF** 和 **PPTX** 幻灯片右下角水印与 Logo 图标而设计的桌面工具。

---

## 🚀 核心特性

1. **PPTX 矢量级无损移除**：
   - 自动遍历每一页幻灯片（Slide）、幻灯片母版（Slide Master）与版式（Slide Layouts）；
   - 精准识别并从底层 XML 架构中彻底删除右下角的 NotebookLM / Google 图标与形状，幻灯片内容 100% 原始矢量清晰。

2. **PDF 像素级涂覆与流抹除**：
   - 采用 PyMuPDF 工业级底层解析引擎；
   - 精准覆盖并擦除右下角水印区域（Redaction 注释抹除机制），生成干净无杂质的 PDF 课件。

3. **双模式支持**：
   - **桌面 GUI 窗口模式**：界面现代化，支持批量拖入文件、整目录扫描、进度条展示、一键打开输出目录。
   - **CLI 命令行模式**：方便脚本自动化或结合批处理命令进行大规模批量清理。

---

## 🖥️ 使用方法

### 方式一：双击直接启动桌面 GUI 应用（最推荐）
直接在资源管理器中双击运行：
👉 `启动_NotebookLM去水印工具.bat`

### 方式二：命令行极速处理
```bash
# 处理单个文件
py -3.12 cli.py "课件.pptx"

# 处理整个文件夹
py -3.12 cli.py "D:\我的NotebookLM课件\"
```
